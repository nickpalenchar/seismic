When work begins on a card, the agent assigned to it is called a **worker**. This agent's prompt guides
them to write quality code. They are also provided with relevant context around other cards' features.

## Recommended Models

While any model with logic could attempt to be a worker, the following generally produce quality results.

- Claude Opus
- Claude Sonnet
- GPT Codex Astra
- GPT Codex Sol
- GPT Codex Terra
